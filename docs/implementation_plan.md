# 实施与验收计划

1. P0：独立建模服务、材料快照、几何/体素统一结构包，核对单位、坐标、哈希和搬移读取。
2. P1：多材料封闭网格、LSF及每对象STL；验证体积、面朝向、材料分区、非重叠与数组范围，明确目标版未实测。
3. P2：两个现有程序增加显式导入求解入口，测试快照确实成为任务几何，材料与输入变化使缓存失效，真3D拒绝。
4. P3：源码GUI、工程和工艺编辑、材料、SEM/TEM、可视预览、单周期/有限阵列和导出，真实Tk验收。
5. P4：端到端合成AH和SEM/TEM检查、适配回归、源码迁移归档、记录实际通过及阻塞。

没有数值仿真结果占位。LSF导出成功不等同目标Lumerical版本验证成功；不伪造FSP。
