# 图形界面与分段调试

启动：`python run_modeler.py gui`。已有依赖时可直接使用自己的解释器；无需复制、封装或安装原来的 Meep / fdtd 软件。

`setup.bat` 只在此源码目录创建或复用 `.venv`，使用 wheel 安装依赖，不提升权限、不修改系统 Python。建议普通 64 位 Python 3.11 / 3.12（带 tkinter、venv、pip）。网络与公司安全策略仍需允许 Python 和 pip。公司实际机器未验证；本机复用既有环境测试，不重装。

如需长期复用已有解释器，在本机创建 `config/local_runtime.json`，内容为 `{"python":"已有解释器的完整路径"}`。源码启动器优先采用它，其次选择本目录 `.venv`，再检查当前解释器已有依赖。此本机配置不进入分发源码包，避免把开发电脑绝对路径带到公司机器；可用 `python scripts/launch_modeler.py --check-only` 验证。

Windows 双击入口先通过系统自带 PowerShell 读取上述配置，再启动 Python，因此不要求已有环境同时出现在 PATH 中；Windows 商店的 Python 占位入口会被跳过。不改系统执行策略或提升权限。公司策略若禁止运行 PowerShell 脚本，仍可直接用选定解释器运行 `run_modeler.py gui`。

启动失败时先查看 `logs/startup_*.log`，其中包含选用的解释器、目录、子进程错误和退出码。诊断命令（在程序目录 PowerShell 执行）：

```powershell
& '.\启动MarkSimModeler.bat' --check-only
& '.\启动MarkSimModeler.bat' --smoke-test
```

后者会创建真实五页界面、运行事件循环并自动关闭，仅用于启动测试。普通双击不传诊断参数，会正常保留主窗口。

## 五个页面

1. 工程与材料：创建/打开工程，真实 n/k 表、波长单位及列映射、常数材料与曲线；缺少 k 时不会自动无损化。只有显式勾选才记录 k=0 近似。
2. Mark / GDS / 工艺：AH32/53/74 模板与目标步骤；母周期、CD、厚度；实际 GDS cell/layer/datatype 选择；工艺增删、排序、启停、材料、刻蚀、填平与包覆膜。顶部和侧壁厚度独立填写。高级 JSON 补充 ROI / 掩模反相及计算单元，不替代主要表单。
3. 几何预览：同一快照的截面图、逐工艺图例与分组表；打开交互 3D。计算分片不会显示成额外工艺层。
4. SEM/TEM 与体素：本地原标注 GUI 提供标尺、ROI 和人工辅助；载入其配置并填写切面/材料标签后重建。可导入结构包/H5/NPZ，或将参数几何转体素；不自动平滑/降维。
5. 导出与报告：选择单元或有限阵列、重复数、条纹长度；导出自家结构包、LSF、逐材料 STL；可选内置材料映射和波长范围。选择新目录，已有目录不会被覆盖。部分失败会保留明确的失败报告，不称为完成。

## 输入与快照

模板与步骤表单均跟踪“待应用”状态。可以分别点击应用；保存或生成时也会统一应用两张表单。修改模板 CD/pitch 不会清掉独立设置的工艺偏置、平移、旋转或厚度；显式改模板高度时才用它更新绑定层。切换步骤会先校验并应用当前表单，错误时留在原步骤。

输入修改会使当前几何失效，必须重新生成才能导出；旧预览仍可作为参照并显示过期提示。保存前服务层校验几何与材料，保留输入历史。关闭或切换工程时对未保存草稿提示。

v0.2.0：关闭/切换提供“保存、放弃、取消”，Ctrl+S 与工具栏保存使用同一入口。工具栏的保存与生成在后台执行；运行期间禁用编辑并显示用时，防止结果对应旧输入。相同输入重复保存不会堆积空历史版本。新工程会清空旧几何图片、材料光谱和导出摘要。

鼠标位于标签/输入区域时可滚动页面；文本、图表和表格保留自己的滚动行为。小窗口可水平滚动宽表单，五个页签和底部状态保持可见。截面图可双击或点击“放大截面图”。错误原文与调用栈写入日志，可用底部按钮查看。

外部几何优先使用自身结构包或相邻 `materials.json`，不会被当前工程的同名材料覆盖；没有配套库时必须明确选择。SEM/TEM 桥接配置声明的材料文件也优先，且相对路径以配置文件所在目录解释。图像参数使用独立版本计数：改动标尺、体素间距、标签或配置会使图像重建快照过期，但不会清空无关的参数几何；任务运行中修改输入也不会把旧结果重新标成当前结构。

SEM/TEM页的“保存当前重建配置…”独立于顶部工程保存：记录当前标尺、切面位置、体素尺寸、标签与确认状态，也允许保存尚未确认的草稿。明确选用的工程材料快照保存为相邻 `.materials.json`；已有材料文件和原图保留路径引用，不复制或修改。请使用新的配置文件名；换电脑后需重新指定原图及外部材料路径。保存草稿不等于通过重建前的标尺与位置检查。

有限阵列仅作用于本次导出，不修改母周期工程；“预览本次导出范围”展示实际重复几何。只有验证过的沿 y 均匀矩形支持长度修改，任意三维形状和体素不能无说明拉伸。

## 代码分工

- `src/markmodel/ui/app.py`：窗口、工程草稿、异步任务、几何视图。
- `src/markmodel/ui/process.py`：Mark 和工艺表单、实际 GDS 选择。
- `src/markmodel/ui/materials.py`：TXT/CSV、未知 k 和 n/k 曲线。
- `src/markmodel/ui/material_import.py`：原始文本预览、编码/分隔符与列映射校验。
- `src/markmodel/ui/transfer.py`：图像桥接、体素、导出选项和报告。
- `src/markmodel/ui/widgets.py`：样式、可滚动页面和通用控件。

GUI 不计算电磁场。几何构建/体素转换在 `service.py`，交换文件在 `exchange.py`，三角网格在 `mesh.py`，Lumerical 在 `lumerical.py`。`ModelerApp.build_now()` / `export_now()` 是同步调试入口，与按钮调用同一服务；工具栏的长任务使用后台线程，不阻塞 Tk 事件循环。

## 当前边界

本工具不运行 FDTD、不生成散射结果，也不写 Lumerical `.fsp`。LSF 目标 2023 R2.1 的目标机运行验证仍需完成。材料表/结构支持能力不等同自家二维求解器能力；接收端必须检查并拒绝超范围结构。SEM/TEM 单截面延伸依然是 2.5D 假设。
