# Mark 与工艺页使用体验排查

日期：2026-10-22。范围为独立建模器的 `src/markmodel/ui/process.py`，没有修改用户工程。

原文件备份：`outputs/ux_audit/backups/process_20261022/process.py`。

## 实际复现的问题与修复

| 问题 | 用户后果 | 本次处理 |
| --- | --- | --- |
| 修改模板 CD 后没有任何未应用状态 | 在真实 Tk 测试中，CD 从 1600 改成 1200 nm，旧结构仍可导出；点击生成后实际仍为 1600 nm | Mark 表单跟踪待应用状态，立即使旧结构失效；保存、生成统一提交 Mark 和工艺表单 |
| 应用工艺步骤会刷新并覆盖尚未应用的 Mark 数字 | CD 草稿 1100 nm 无声变回 1600 nm | 刷新 Mark 时保留待应用草稿；新增 `commit_pending_inputs()` 统一处理顺序 |
| 应用 Mark 会归零独立工艺偏置 | CD 偏置、平移、旋转和用户层名丢失 | UI 调用模板生成后保留这些独立工艺参数；仅修改 CD/pitch 时也保留单独调整的工艺厚度 |
| 没有说明表单尺寸是否对应实际结构 | 用户可能把输入框当成已生效参数 | 显示“待应用”、派生子 pitch、条纹数和尺寸校验信息；工程路径旁显示待应用状态 |
| 删除步骤后仍显示已删除步骤并允许编辑 | 编辑内容没有对应对象，点击应用才失败 | 自动选择邻近步骤；没有步骤时清空并禁用表单 |
| 上移、下移、GDS 等按钮在不适用时可点 | 位于边界时无反应，衬底也能进入 GDS 选择 | 根据选中位置、步骤类型禁用不适用操作；GDS 在打开文件框前检查步骤类型 |
| 工艺类型切换保留旧参数 | 特别是旧 `mask_polarity=negative` 会让新的均匀层使用空掩模；旧刻蚀参考面可能错误显示为添加层起点 | 按操作清理专属字段，坐标从当前操作对应字段读取；薄膜形貌切换清理不适用侧壁厚度 |
| 错误数值提示只显示英文字段或 Python 转换错误 | 用户无法定位该改哪个输入框 | 使用中文字段名，拒绝空白、NaN、无限、非正厚度；禁用字段不参与数值解析 |
| 自定义 GDS 可与未应用模板竞争同一步骤 | 下一次保存可能又被模板 GDS 覆盖 | 对该冲突给出明确错误，先应用模板再选自定义 GDS；不静默选择其中一方 |
| GDS 图层数值可能被 `int()` 截断 | 9.2 被当成图层 9 | 严格检查整数；文件无实际多边形时明确提示；只列出有可用图形的 cell |
| GDS 选择弹窗未锁定原工程 | 主窗口切换工程后回调可能操作新工程 | 使用公共 `make_modal`，窗口依附原工程 |
| 高级步骤 JSON 允许重复 ID 等明显错误 | 工艺列表和 Mark 绑定损坏，稍后才报错 | 提前检查 ID 唯一性、操作、布尔启用状态、材料列表、掩模和薄膜模式类型 |
| 中文逗号分隔目标材料不识别 | 刻蚀/删除多个材料时无法应用 | 兼容中文逗号并去除重复名称 |

## 状态和优先关系

- 修改 Mark 或工艺表单会使已有结构过期；必须重新生成才能导出。
- 保存、生成会提交两张表单，不需要分别点击两个“应用”按钮。
- 模板 CD/pitch 是名义掩模尺寸，工艺 CD 偏置、平移、旋转独立保留。
- 只改模板 CD/pitch 时，已单独调整的工艺厚度继续保留。显式修改模板高度、绑定目标或 Mark 类型时，模板高度用于绑定层。
- 删除步骤是明确的移除操作；若删除模板绑定目标，对应待应用模板绑定随之取消。
- 没有掩模的操作作用于整个计算单元；步骤说明明确显示这一点。
