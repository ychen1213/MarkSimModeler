# SEM/TEM、体素与导出使用体验检查

检查日期：2026-10-23。检查对象：`src/markmodel/ui/transfer.py`。

修改前备份：`outputs/ux_audit/backups/transfer_20261022_234526/transfer.py`。
所有复现工程、图像和导出文件均由测试在临时目录创建，没有修改用户已有工程。

## 已复现并修复

| 场景 | 原问题 | 现在的行为 |
| --- | --- | --- |
| 载入旧版原始图像标注 JSON | 继承上一次合成演示的 TEM 位置、配准和材料，配置来源失真 | 原始标注不继承旧桥接数据；提供 TEM 原点、方向、高度表单，并要求真实图明确确认 |
| 载入不合法的配置 | 先改写当前 `image_spec`，随后校验失败，当前输入被部分污染 | 临时解析、校验全部成功后再接收；失败保留原输入和当前模型 |
| 桥接配置使用单一体素尺寸 | `spacing_um: 0.04` 在表单更新中报错 | 支持标量或 `[x,y,z]`，标量明确扩展为三轴同值 |
| 使用 `{y:3,x:2}` 格式标尺 | 字典值的插入顺序可能改变坐标轴含义 | 按键名读取 x/y；未知键、布尔值、NaN 和非正标尺拒绝 |
| 修改真实图的 nm/px | 新数值沿用旧的“已标定”确认 | 修改标尺后取消确认，用户重新核对；重建快照记录本次手工确认与实际数值 |
| 修改 TEM 切面位置、方向或高度 | 无明确确认状态 | 修改后取消位置确认，真实图重建前要求核对 |
| 从工程页切换到合成图重建 | 自动借用当前工程的同名材料，演示可能被静默替换为另一套 n/k | 默认使用合成演示自己的材料；自定义材料必须明确选择 |
| 使用真实图重建 | 材料来源未明确、材料标签拼错等问题到长任务结束后才报错 | 启动前检查图像路径、确认状态和材料映射；提供“选择材料表”与“明确使用当前工程材料” |
| 重建过程中材料源改变 | 可能从变化后的文件获取材料 | 启动前读取并复制所选材料快照；工程材料的后续改动不改变已选快照 |
| 高级标注配置添加第 4 种材料标签 | UI 暗示保留任意标签，但底层只支持固定三类 | 直接说明当前只支持 0 背景、1 衬底、2 条纹，额外标签在启动前拒绝 |
| 对已有体素再次点击转换 | 启动后台任务后才收到英文错误 | 立即说明已有标签无需转换，不会默默重采样材料 ID |
| 仅导出结构包 | 无关的半填波长或非法三角数阻止导出 | Lumerical 相关输入禁用并忽略；结构包可独立正常输出 |
| 未勾选 Lumerical 但保留辅助 STL 勾选 | 似乎选择了 STL，实际不会生成 | STL 控件随 Lumerical 联动禁用；输出设置明确 `stl=false` |
| 单元导出和有限阵列切换 | 无关的重复数、长度一直可编辑，易误解是否生效 | 单元模式禁用这些输入；有限阵列才解析，并给出具体字段的中文错误 |
| 几何范围预览 | 材料波长或三角数填写不完整时无法预览几何 | 预览仅解析几何范围；与正式导出共用同一个实际重复/长度变换，不替换原模型 |
| Lumerical 内置材料映射 | 允许映射未使用的材料，后续导出报错；编辑窗不绑定当前模型 | 仅列出当前结构使用的材料，窗口为模态；新模型接收时由应用清空旧映射 |
| 导出完成 | 界面直接显示一长段 JSON，难以找到入口 | 显示中文摘要、材料、范围、对象数和实际入口；完整 JSON 保存在文件，并提供打开按钮 |
| 结构包写完后 Lumerical 导出失败 | 只显示底层错误，不说明已有文件是否完整 | 保存 `partial_export_failed` 报告，错误明确列出报告路径，说明该目录不是完整导出，需要新目录重试 |
| 未选择任何输出 | 先弹出路径选择，确认后才报错 | 先提示至少选择一种输出，不再要求无效的路径操作 |
| 导入改名的结构包入口 JSON | 按文件名判断，可能误要求再选择材料 | 按 JSON `format` 识别结构包；服务层也由主开发同步修复 |
| 修改本页标尺、位置和材料后退出 | 顶部工程保存不包含图像桥接配置，也没有独立保存入口 | 增加“保存当前重建配置…”；独立保存实际输入与确认状态，未确认草稿可以保存和回读 |

重建配置保存不会覆盖已有 JSON。明确采用当前工程材料时，将当时的材料快照保存为同目录的 `配置名称.materials.json`，配置采用相对引用；这两个文件需要一起携带。如果选择的是现成材料 JSON，则配置保留该文件的明确路径引用。原图仅记录绝对路径，不复制、不改写；跨电脑使用前需重新指定原图和外部材料文件的位置。界面明确说明该入口与顶部的工程保存互相独立。

## 本次没有扩展的能力

- SEM/TEM 入口仍是单截面模板延伸的 2.5D 重建，不是任意三维断层测量。
- 目前桥接材料角色仍只有背景、衬底、条纹三类。任意多材料图像分割需要另一项实现，不能靠多写标签假装支持。
- 已有体素不在此入口自动重采样或拉伸；真实三维形状不能冒充二维求解器可用结构。
- Lumerical 2023 R2.1 尚未实际运行本次导出脚本。Python 文件验证不能代替目标版本执行和材料色散拟合验证，界面继续明确显示这一点。
- 图像标尺与 TEM 位置确认是用户提供的实验信息，本程序不能仅凭确认框验证实验标定正确性。
